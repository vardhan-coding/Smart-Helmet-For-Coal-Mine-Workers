# Smart Helmet For Coal Mine Workers

## Overview
The Smart Helmet Safety Monitoring System is a Python-based safety solution designed for workers in hazardous environments such as mines and industrial areas. The system simulates monitoring of environmental conditions to ensure worker safety.

## Problem
Workers in hazardous environments face risks from gas leaks, high temperatures, and unsafe environmental conditions.

## Solution
This project implements a Python-based monitoring system that detects abnormal environmental parameters and triggers alerts to improve worker safety.

## Key Features
- Gas level monitoring simulation
- Temperature monitoring
- Safety alert generation
- Hazard detection logic

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Clone or download the repository.
3. Run the program:
   python smart_helmet_system.py
